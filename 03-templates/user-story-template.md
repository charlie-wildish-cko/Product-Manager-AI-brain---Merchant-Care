- [ ] All acceptance criteria met
- [ ] Code reviewed and merged

- [ ] QA tested and approved

- [ ] Support team trained (if needed)
- [ ] Feature flag configured (if applicable)
- [ ] Monitoring/alerting set up
- [ ] Stakeholders notified
