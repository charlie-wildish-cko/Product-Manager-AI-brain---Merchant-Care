Content surface — 16px radius, subtle border, white background. Compose anything inside.

```jsx
<Card elevated>
  <h3>Authorization rate</h3>
  <p>98.4%</p>
</Card>
<Card interactive as="a" href="#">Clickable card</Card>
```

`elevated` swaps border for the soft shadow; `interactive` adds hover lift. Default padding is 24px.
