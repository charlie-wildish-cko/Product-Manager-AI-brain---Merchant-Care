## Review panel: VP of Product (Taylor) pass

*This section records the VP lens applied to this template. See [document-review-panel.md](../02-workflows/document-review-panel.md). Remove or fold away when using the template.*

**Lens**: Clarity and defensibility for leadership; alignment between problem, goals, scope, and recommendation; explicit ask for advocating upward; support/ops impact surfaced for the CPO.

### What works well

- **2-minute read**: Summary is capped at 3 sentences and explicitly asks for “what we recommend or need,” so a CPO can get the ask quickly.
- **One takeaway**: The Recommendation section already instructs authors to state “the one thing you want everyone (including support/ops) to remember” in Summary or there—good for VP advocacy.
- **Support/ops in the ask**: The optional line in Recommendation (“If this affects support or operations—what do frontline teams need to know or do, and when do ops need to be ready?”) gives the VP something concrete to represent to the CPO.
- **Scope**: Background asks for in/out of scope, which supports alignment between problem, scope, and recommendation.

### Gaps and suggested tweaks

1. **Cut/delay clarity**: The VP needs to know “what would we cut or delay if we had to?” so they can represent it accurately. The template only optionally mentions “what we’re not doing or deprioritising” in Recommendation. Consider adding a short, explicit prompt there, e.g. *“If we had to cut scope or slip timeline, what would we drop or delay? State it in one line.”*
2. **Trade-offs**: There’s no dedicated place for “trade-offs we’re making” (e.g. vs other initiatives). Adding one optional line in Recommendation or What this means would help the VP answer “why this over other things?”
3. **One thing to remember**: Making it a dedicated, optional line (e.g. *“One thing we want everyone to remember: …”*) in Summary would make it easier for the VP to lift and repeat upward.
4. **Risks**: Key assumptions/risks are optional in Recommendation. The VP lens wants “are we being honest about risks?”—consider keeping that prompt visible so authors don’t skip it when it’s relevant.

### Verdict

The template already supports a CPO-ready, 2-minute narrative and surfaces support/ops impact. Strengthening the prompts for “what we’d cut if we had to,” trade-offs, and the single takeaway would make memos easier for the VP to advocate for with leadership.
