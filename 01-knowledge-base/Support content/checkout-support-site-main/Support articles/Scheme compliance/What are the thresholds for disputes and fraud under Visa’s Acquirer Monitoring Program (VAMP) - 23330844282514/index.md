For merchants, these thresholds only apply where the total number of transactions reported as fraud plus disputes is:

- **Outside of MENA:** Greater than 1,500
- **In MENA:** Greater than 100 and over 75,000 USD in value

**Note:** Visa made a significant update to how they calculate the program ratios, with corresponding increases to the thresholds at which these ratios result in scheme fees. 

For more information, see [Update to the Visa Acquirer Monitoring Program (VAMP)](https://support.checkout.com/hc/en-us/articles/26990138066450).
