The Visa Acquirer Monitoring Program (VAMP) comes into effect from June 1, 2025.

For the first three months of the program, Visa provides a grace period before assessing fines. Visa also provides a three-month grace period for first-time identifications within a rolling 12-month period.

Fraud and dispute thresholds under the VAMP will decrease from April 1, 2026.

**Note:** Visa made a significant update to how they will calculate the program ratios, with corresponding increases to the thresholds at which these ratios will result in scheme fees.

For more information, see [Update to the Visa Acquirer Monitoring Program (VAMP)](https://support.checkout.com/hc/en-us/articles/26990138066450).
