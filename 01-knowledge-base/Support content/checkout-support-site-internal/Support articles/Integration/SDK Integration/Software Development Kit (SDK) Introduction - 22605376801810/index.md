**Use this article to**

Understand what a Software Development Kit (SDK) is as part of our Connect productINTRODUCTION TO SDKs ℹ️

An **SDK** is a toolkit that gives merchants a straightforward way to integrate with the Checkout.com platform. SDKs are designed for technical users like developers and software engineers who are responsible for coding the integration.

Essentially, our SDKs provide a simpler way for a merchant's application to communicate with our core Application Programming Interfaces (APIs). Using an SDK saves developers from writing extra code and managing complex requirements on their own.

We offer three main types of SDKs:

- 
**Back-End SDKs**: Allow the merchant's server to talk to our API

- 
**Front-End SDKs**: Help merchants build payment forms into their website's user interface

- 
**Mobile SDKs**: Specifically designed for iOS and Android apps, which are often required for PCI compliance

SDK INTEGRATION PROCESS 🖊️

Understanding the integration journey is key to diagnosing their problem. They'll typically follow these three steps to integrate an SDK. 

## Step 1: Developer Installs the SDK

The developer first chooses and installs the SDK that matches their application's programming language (e.g., Node.js, Java, PHP) or platform (e.g., iOS, Android).

- [Android SDK](https://www.checkout.com/docs/developer-resources/sdks/3ds-sdks/3ds-android-sdk)

- [iOS SDK](https://www.checkout.com/docs/developer-resources/sdks/3ds-sdks/3ds-ios-sdk)

## Step 2: Initialize the SDK

Next, the developer initializes the SDK within their code using their API keys. This step authenticates their application so it can communicate with our platform.

## Step 3: Use the SDK Methods

Finally, the developer uses the functions or "methods" provided by the SDK to perform actions, such as requesting a payment. The SDK takes care of formatting the request correctly for our API.

✅ **What This Achieves:** When complete, the merchant's application can manage the entire payment flow using the SDK, which is tailored to their specific front-end or back-end language.
FAQs**❓**
Which SDK should I use?You should choose the SDK that matches the programming language of your application. For example, if your server runs on Java, you would use our Java SDK. We have different SDKs for back-end, front-end, and mobile applications
