## INTRODUCTION TO FLOW** 💬**

**Flow** is a pre-built, customizable payment User Interface (UI) that is embedded directly into a merchant's website. It allows merchants to accept payments using a global network of payment methods through a single integration.

[Flow AI Assistant](https://docs.google.com/document/d/14j3WWhRfbD6rkPxXHQhvFWb5MKyFSaZXCIE6jrxIWdE/edit?tab=t.0) 🤖

## **Key Features**

Flow is an intelligent, all-in-one payment solution that manages the full payment journey for the customer.

- 
**Secure and Compliant:** Provides built-in support for **3D Secure (3DS)** and handles the tokenization of sensitive payment details.

- 
**User-Friendly:** Features **input masking** (hiding sensitive data as it's typed) and validation to reduce user errors.

- 
**Dynamic and Customizable:** Automatically shows the most relevant payment methods to a customer based on their device, location, and currency. The UI can be customized to match the merchant's branding.

- 
**All-in-One Integration:** Offers numerous payment methods (e.g., cards, Apple Pay, Google Pay, iDEAL, Klarna) through a single, low-maintenance integration.

**INTEGRATING FLOW ✅**

When a merchant integrates Flow, they only need to complete three main steps:

1. 
**Request a Payment Session:** This is done via an API call containing information about the payment, such as the amount and customer details.

2. 
**Create a Space:** The merchant designates a container or space on their website where the Flow payment form will be displayed.

3. 
**Add the Script:** The merchant adds the Payment Components script and initialization code to their website. This will make Flow appear and function on their checkout page.
Merchant facing documentation: [Get Started with Flow](https://www.checkout.com/docs/payments/accept-payments/accept-a-payment-on-your-website/get-started-with-flow)

 
 
**KEY TAKEAWAYS 🔑**

Flow manages the entire payment process from start to finish

- It securely **tokenizes** sensitive payment details

- It displays the available payment methods to the customer

- It **captures** any necessary customer data required for the chosen method (e.g., an IBAN for an iDEAL payment)

- It handles complex authentication flows like **3D Secure (3DS)**

 

## **FAQs ****❓**

How is Flow different from Frames?Frames is a tool designed only to securely collect card details. Flow is a complete, end-to-end solution that not only collects payment details but also manages the entire payment process and offers many different payment types (not just cards) in a single integration.Can merchants add new payment methods with Flow?Yes. Flow can dynamically display payment methods and new options can be deployed without requiring any new code changes from the merchant.
