**Use this article to**

Escalate a support request to the Product and Engineering team when the issue is technical, requires a code fix, or involves an unexpected product behavior that cannot be resolved through standard troubleshooting steps.ESCALATION DETAILS ⬆️

To escalate an issue to the Product and Engineering team, you must [raise a Jira](https://checkout.atlassian.net/servicedesk/customer/portal/111/group/462/create/277)[.](Fresh%20Service%20form%20) Follow these steps to ensure all required information is included.

- 
**Access the Jira Service Form**: Navigate to the Jira portal to create a new request.

- 
**Select the Product Team**: From the dropdown menu, choose **"Payment Interfaces."**

- 
**Complete the Form Fields**: Fill in the following information accurately

- 
**Summary**: Provide a brief, concise description of the issue

- 
**Description of Request**: Provide a full, detailed description of the issue, include key information such as:

  - Any error messages

  - Context (e.g., does the issue only happen in a specific browser, on web, or on mobile?)

  - Steps to reproduce the issue

  - The expected outcome versus the actual outcome

  - The impact on the merchant or user

- 
**Merchant Name**: Enter the name of the client as it appears in CAT

- 
**Business Name**: Enter the name of the entity as it appears in CAT

- 
**Affected Channel(s)**: Provide the ID of the processing channel

- 
**Is merchant Tier 1 or 2**: Select "Yes," "No," or "Unknown."

- 
**Environment**: Specify if the issue is occurring in "Product" or "Sandbox"

- 
**Is this affecting live processing for the merchant?**: Select "Yes" or "No"

- 
**Payment ID(s)**: Provide any impacted payment IDs.

- 
**Correlation ID(s), Track ID(s), or Context ID(s)**: Include any IDs that would help with troubleshooting, such as the payment session ID

- 
**Link to Slack**: If a Slack thread exists with relevant context, provide the link
