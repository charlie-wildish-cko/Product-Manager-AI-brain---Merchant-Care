## Process Steps

Teammates and engineers have access to test stores to recreate and troubleshoot merchant configurations. For a list of available test shops as well as login credentials, please refer to the following Confluence page:

- [Test Shops](https://checkout.atlassian.net/wiki/spaces/FS/pages/714375290/Test+shops)

**Please note**

- **Teammates should not change any settings on the Magento test store**

- For Shopify, teammates can create test stores and update the settings to suit their needs

It is also worth asking the merchant for a screen recording or screenshot to illustrate the issue if we’re unable to reproduce it for all e-commerce integrations.

If the merchant continues to experience issues, please submit a query in the dedicated Slack channel for the merchant's e-commerce platform:

- **#shopify**

- **#magento**

- **#bigcommerce**

- **#woocommerce**

- **#prestashop**

- **#ecommerce_platforms**

- **#ask-docs**

If further assistance is needed, raise a ticket through [Support Portal - Raise a Ticket](https://checkoutsupport.freshservice.com/support/catalog/items?category_id=50000052438) and a dedicated engineer will review and address the issue.
