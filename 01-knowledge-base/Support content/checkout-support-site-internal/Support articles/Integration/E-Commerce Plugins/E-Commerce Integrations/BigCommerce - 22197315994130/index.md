## Introduction

Checkout.com supports integration with multiple e-commerce platforms. For a complete list of supported platforms, refer to the following Confluence page: [E-Commerce Platforms](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/1453593232/E-Commerce+Platforms)

For some issues specific to eCommerce platforms, there are instances where the plugin installed by the merchant within their environment is an older version, so it is best to review the release notes to check if the issue raised has been resolved by a more recent version of the plugin.

## Process Steps

Most BigCommerce issues stem from merchant-side misconfigurations. However, certain problems, such as the payment status needing to be updated correctly, may result from issues related to the order in which events are sent.

Note: For Sandbox usage, additional enablement is required for BigCommerce to use NAS keys. This can be requested by providing the store URL in the #bc_checkoutcom channel.

Please refer to the following confluence page, [BigCommerce Guide & Resources](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/5891129405/BigCommerce+Guide+Resources) for further troubleshooting steps

The external BigCommerce guide is available [here](https://support.bigcommerce.com/s/article/Connecting-with-Checkoutcom?language=en_US).
