## Introduction

Checkout.com supports integration with multiple e-commerce platforms. For a complete list of supported platforms, refer to the following Confluence page: [E-Commerce Platforms](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/1453593232/E-Commerce+Platforms)

For some issues specific to eCommerce platforms, there are instances where the plugin installed by the merchant within their environment is an older version, so it is best to review the release notes to check if the issue raised has been resolved by a more recent version of the plugin.

## Process Steps

Checkout.com collaborates with subscription platform partners such as Zuora and Chargebee. Partnerships facilitate the seamless setup of recurring subscriptions every month for merchants.

1. Subscription platforms (Chargebee, Zuora etc.) are generally configured on the merchant’s side, so for detailed integration processes and setup guidelines, refer them to specific collaboration notes and materials provided by partners like [Zuora](https://knowledgecenter.zuora.com/Zuora_Payments/Payment_gateway_integrations/Supported_payment_gateways/Checkout.com_payment_gateway_integration) and [Chargebee](https://www.chargebee.com/docs/checkout-gateway.html).

2. For any complex cases in which merchants are unable to self-serve, please reach out to the platform owners listed [here](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/1448509562/Partner+Statuses).
