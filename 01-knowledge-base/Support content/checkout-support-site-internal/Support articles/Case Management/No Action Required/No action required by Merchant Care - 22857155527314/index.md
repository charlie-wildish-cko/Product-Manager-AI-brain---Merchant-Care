## Process Steps

If no action is required by Merchant Care, the agent should: 

- Select the macro “No Action Required” that can be found in the “Dispatch” macro folder and submit the case. Upon submission, this macro will:

  - Automatically add the following private note to the ticket: “No action required from Merchant Care, hence solving the ticket.”, 

    - Note: if additional comments are needed, please add them to the private note before submitting the case. 

  - Automatically close the ticket. 

 **Note**: 

- For more specific scenarios where no action is required by Merchant Care, please see the rest of this SOP.
