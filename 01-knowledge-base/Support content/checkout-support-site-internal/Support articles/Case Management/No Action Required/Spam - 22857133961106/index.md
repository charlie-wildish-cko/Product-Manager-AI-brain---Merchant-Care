## Introduction

Spam emails have no relevance to Checkout or our merchants. Typical spam emails include: 

- Advertising emails, 

- Invitations to events such as conferences, 

- CVs for jobs, etc.

## Process Steps

If the Merchant Care agent recognises the case to be Spam, the agent should: 

- Select the macro “Spam” that can be found in the “Dispatch” macro folder and submit the case. Upon submission, this macro will:

  - Automatically add the following private note to the ticket: “This ticket is spam and does not require any Merchant Care input - using this macro to tag and solve the ticket.”, 

    - Note: if additional comments are needed, please add them to the private note before submitting the case, 

  - Automatically tag the ticket as Spam, and 

  - Automatically close the ticket.
