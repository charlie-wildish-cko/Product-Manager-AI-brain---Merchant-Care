**When to use this article**

For guidance on handling email cases where Merchant Care is CC'd but no direct action is required.DESCRIBE THE ISSUE 💬

Agents receive email communications where Merchant Care is included in the CC field rather than the primary "To" field. The agent is uncertain whether any action is required from their end, as the emails often seem to be for informational purposes only. KEY TAKEAWAYS 🔑

- 
**Review first, then act:** Always review the email to confirm that Merchant Care is a secondary recipient and no action is explicitly requested

- 
**Document everything:** Before solving the ticket, add a private note with a concise explanation, such as "No action required from Merchant Care" and include any other relevant details

- 
**Solve, don't ignore:** Once you've confirmed no action is needed and have documented the case, mark the ticket as "Solved"

- 
**Context is key:** The process varies slightly depending on whether the email includes internal teams only or if a merchant is also a recipient

PROCESS FOR MANAGING EMAIL CASES 🖊️

1. 
**High-level assessment**

  - Assess the email to identify the primary recipient

  - Confirm that Merchant Care is only in the CC field

  - Read the email content to see if any specific action is requested from Merchant Care

2. 
**Scenario: Merchant Care is CC'd and no action is required.**

  - 
**Review:** Confirm that Merchant Care is not the primary recipient and no action is requested.

  - 
**Document:** Add a private note to the case explaining, "No action required from Merchant Care, hence solving the ticket."

  - 
**Note relevant details:** If any follow-up information or context is provided, document it in the private note.

  - 
**Solve:** Submit the ticket as "Solved." **Only take this action if no action is required from Merchant Care.** 

  - If it is part of an ongoing case, ensure the communication is logged appropriately, but no further steps are needed.

3. 
**Scenario: Communications with internal teams only**

  - 
**Review:** Confirm the communication is for internal purposes only and no action is requested from Merchant Care

  - 
**Document:** Add a private note explaining, "Closing on our end, thanks for the update. Let us know if you need anything else."

  - 
**Note relevant information:** If the email contains important updates or changes that might affect other cases, document this context in the private note

  - 
**Solve:** Submit the ticket as "Solved."

4. 
**Scenario: Communications where the merchant is included**

  - 
**Review:** Carefully review the email to confirm the merchant is included and that no explicit action is requested from Merchant Care

  - 
**Document:** Add a private note explaining, "No action required from Merchant Care, marking ticket solved"

  - 
**Note critical updates:** If the merchant has shared any critical updates or details, add this context to the private note

  - 
**Solve:** Submit the ticket as "Solved"

ESCALATION ⏫

If an email seems to require action but the path forward is unclear, an agent should:

- Add a private note outlining the situation and their uncertainty

- 
Tag a senior agent or team lead for guidance
