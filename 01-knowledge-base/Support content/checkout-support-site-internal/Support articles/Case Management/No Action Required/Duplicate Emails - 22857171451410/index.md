## Introduction

Duplicate emails are typically sent by a different individual from the same company, i.e. the request is coming from the same merchant but just a different user. 

## Process Steps

To identify duplicate emails, agents can go through the queues and check for tickets from the same merchant with the same or similar subject name. 

If the Merchant Care agent recognises that the ticket is a duplicate of an existing ticket, they should merge it into the original ticket. 

To do this, please follow the guidance [here](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/5969477651/Dispatch+Process+-+SOP).
