**When to use this article**

If a merchant requests an update to their Tax Registration Number or TRN, this must be escalated to the Merchant Configuration team.INTRODUCTION 💬

A TRN number, or Tax Registration Number, is a unique identifier assigned to businesses for tax purposes. It is typically used to identify a business entity in tax-related matters, such as VAT registration. PROCESS TO UPDATE A TRN 🖊️

This request must be actioned by the **Merchant Configuration Team**. Please use the relevant internal macro to communicate this request and ensure all mandatory fields are included. 

| Use this Macro: Transfer > Merchant Configuration > Region |
| --- |

The following information must be included in the system update request:

- **Merchant Name:** 

- **Client ID:**

- **Account Structure:** 

- **Action/Issue Summary:** Update the merchant's Tax Registration Number (TRN) in the system to ensure future tax invoices include the correct TRN.

The merchant configuration team will respond to confirm this has been actioned, you should reply to the merchant and confirm the TRN has been updated.
