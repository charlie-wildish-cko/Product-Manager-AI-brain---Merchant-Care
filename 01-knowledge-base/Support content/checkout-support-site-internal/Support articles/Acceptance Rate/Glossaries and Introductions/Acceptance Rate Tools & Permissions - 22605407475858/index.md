## Tools & Permissions

Below are the tools that Merchant Care use to handle issues related to Acceptance Rate:

| **Tool** | **Purpose** |
| --- | --- |
| **Dashboard ** | The Dashboard is a single source for keeping track of and analyzing all payments in terms of critical performance indicators, payment history, data, and analytics.  The Dashboard is the Portal version for merchants on the New Account Structure (NAS) and Gateway Core (GWC). |
| **CAT Admin Tool ** | The Client Admin Tool (CAT) is a user interface (UI) plugin and API. The internal admin tool is used by the Merchant Configuration team to setup new clients and manage the configuration settings of our customers' accounts on the New Account Structure (NAS). The Client Admin Tool integrates directly into the NAS product network, reflecting the most up to date product offering from the respective domains. Merchant Care agents can use CAT Admin Tool to verify user configuration settings during their case investigation. |
| **Retool** | Retool is a low-code UI technology to build internal tools with its drag-and-drop building blocks and connect capabilities.  There are two Retool clusters hosted within Checkout; Staging and Production. Staging is used by product teams to develop Retool apps, whereas Production is used by other teams to read and update information on CAT and Hub.  Merchant Care agents can use Retool to perform queries using payment IDs and obtain further information on specific transactions. |
| **Datadog** | Datadog is a monitoring tool that is used by [Checkout.com](http://checkout.com/) to monitor cloud-based applications alongside allowing the ability to monitor servers, databases, tools and services we provide.  Merchant Care agents use Datadog for monitoring and investigating issues raised by merchants. |
| **Looker** | Looker is a powerful business intelligence (BI) software and big data analytics platform that helps to explore, analyze, develop, and share insightful real-time visualizations. In Looker, there are a range of pre-built dashboards that are used to understand and analyze the data. Looker application is managed by the BI Team. Looker is used by Customer Support mainly to extract reports related to payment from the payment backend (Dashboard of a transaction). |
| **Zendesk ** | Case management platform for handling merchant tickets and responses. |
