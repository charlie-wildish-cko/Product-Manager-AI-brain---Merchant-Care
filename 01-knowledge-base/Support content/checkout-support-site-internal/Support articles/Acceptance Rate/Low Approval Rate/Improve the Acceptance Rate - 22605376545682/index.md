**Use this article when**

A merchant requests information on how to improve the acceptance rate.INTRODUCTION TO ACCEPTANCE RATES 💬

The acceptance rate is a reflection of a merchant's success across all stages of the payment lifecycle. To improve the acceptance rate, merchant's should follow the guidance to improve the success rate at each stage of the payment lifecycle:

- [Optimize payments](https://www.checkout.com/docs/payments/optimize-payments)

- [Improve authorization rate](https://www.checkout.com/docs/business-operations/monitor-payment-performance/authorization-analytics#Improve_authorization_rate)

CHECK FOR INCIDENTS 👀

First of all, [check for incidents](https://checkoutint.zendesk.com/hc/en-us/articles/22605423800978-Acceptance-Rate-Drop-Checking-if-it-s-Incident-Related) - if there aren't any then follow the escalation guidance below.ESCALATION ⬆️

- If the merchant is using Intelligence Acceptance: Raise the request with the Performance Team via the #ask_performance Slack channel.

- If the client is NOT using Intelligence Acceptance: Contact the client's TAM/AM (Technical/Account Manager) with your findings. 

**Integration Feedback Escalation**

- If the investigation suggests a specific change in the merchant's integration is needed: Escalate the request to the Merchant Care L2 Team for technical assistance. Also, notify the applicable Sales Engineers/TAM/AM.
