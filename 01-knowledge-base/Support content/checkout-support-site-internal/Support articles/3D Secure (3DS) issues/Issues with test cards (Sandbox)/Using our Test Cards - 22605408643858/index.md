## Introduction

Issue: Test Card not working within SandBox. When using the test cards simulator the payment is not working as intended. The merchant had used the cardholder’s card to process payments within the simulator to check if their integration would work with payment flow. If the merchant would like to use Sandbox, they must use test cards.

## Process Steps

1. Check the integration

2. Check the protocol version

3. Check the merchant has selected a test card

**Resolution**

The merchant would need to use the test card within our simulator to get a result to work as intended, if another card is used, which is not a part of our test card documentation then this issue would cause a failure or issue may occur. 

Please see the link below for further assistance: [https://www.checkout.com/docs/developer-resources/testing/test-cards#Default_cards_and_responses](https://www.checkout.com/docs/developer-resources/testing/test-cards#Default_cards_and_responses)

If this issue persists then this issue would need to be escalated to the L2 team to investigate this issue further.
