## Process Steps

1. Obtain the Processing Channel ID from Retool or Datadog

2. Open the Client Admin Tool, and in the **Search By** field, enter the **Processing Channel ID** and click **Search** 

3. On the **Gateway processing channels** profile, click on the **Authentication Processing Channel**

1. Check that the channel is currently inactive

1. If the processing channel is inactive, consult the Merchant Configuration team to understand why the channel was disabled
