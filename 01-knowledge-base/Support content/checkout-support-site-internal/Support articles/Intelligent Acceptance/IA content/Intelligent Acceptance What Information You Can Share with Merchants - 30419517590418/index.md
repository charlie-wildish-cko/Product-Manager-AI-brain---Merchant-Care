**When to use this article**

To see what performance data and information about Intelligent Acceptance (IA) can be safely shared with merchants and what should remain for internal-only use.

## 

TOOLING**📍**

| Tools | Access |
| --- | --- |
| [Checkout.com Dashboard](https://checkoutint.zendesk.com/hc/en-us/articles/dashboard.checkout.com) **Environment:**** **Sandbox and Production | **Permissions:**** **Super User (both environments) - Super Admin ( sandbox only) ** Access granted via**** ******[jira](https://checkout.atlassian.net/servicedesk/customer/portal/111/group/296/create/274) |

## KEY TAKEAWAYS 🔑

When communicating with merchants, you are approved to share the following sources and specific data points:

- The Checkout.com Dashboard

- Public Documentation on the external Knowledge base

- Specific Data Exports

- Please note this information can only be shared with the merchant and it should not be shared with 3rd parties or other entities that are not the merchant

## IA DASHBOARD INFORMATION 🖊️

Use the dashboard as your primary communication tool for IA performance. All its information is safe to share, including Key Metrics for:

### Merchant AR (Acceptance Rate)

### AR Boost

### Transactions Optimised

### Revenue Boost

- 
**Optimizations Applied**: This section clearly shows the source of the AR boost (e.g., 3DS, Network Tokens)

CHECKOUT PUBLIC KNOWLEDGEBASE DOCUMENTATION 🧠

You should direct merchants to the [official public documentation](https://support.checkout.com/hc/en-us/search?utf8=%E2%9C%93&query=intelligent+acceptance) on the Checkout.com website regarding Payment services that power performance.

SPECIFIC DATA EXPORTS 📈

The following exports can be shared with merchants upon request:

- An extract of transactions optimised over the last seven days ✅ This export can be **self-served** by the Account Manager using the internal IA Retool dashboard.

- A list of successfully retried transactions ⚠️  this list must be requested via escalation.

INTERNAL ONLY INFORMATION ❌

| Information Type | Description & Why It's Internal-Only |
| --- | --- |
| **The Internal Retool Dashboard** | Do not share screenshots or raw data directly from this dashboard  This is an internal tool to help Account Managers understand merchant performance and is not meant for direct merchant sharing |
| **Specific Retool Tabs/Views** | Do not share the **"Aggregated IA data overview"** tab (shows weekly performance and confidence levels)  The detailed view of performance per optimisation type is also internal-only |
| **Legacy Optimisations** | These are baseline optimisations all Checkout merchants benefit from _without_ being onboarded to IA They are not billed or shared |
| **Shadow Mode** | This involves onboarding a very low percentage of volume against a control group without merchant onboarding to IA |

## ESCALATION** ⏫**

- Avoid discussing "legacy optimisations" or "shadow mode enablement" as sharing this can cause confusion and devalue the paid IA product.

- If a merchant requests specific data marked as internal-only, do not share it. Escalate the request to the intelligent-acceptance team via [jira](https://checkout.atlassian.net/servicedesk/customer/portal/111/group/462/create/277) for guidance on how to respond.
