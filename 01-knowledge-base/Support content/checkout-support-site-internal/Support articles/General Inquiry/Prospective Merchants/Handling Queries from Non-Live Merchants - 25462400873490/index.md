**When to use this article**

A merchant that is not yet live with Checkout.com contacts Merchant Care with a sales query or issue, these should be handled by the Sales Team.INTRODUCTION ON NON-CKO MERCHANTS 💬

A **non-CKO merchant** is registered with Checkout.com but is not yet processing live transactions. This includes:

- **Non-live merchants:** Businesses with an account that is not yet active for processing payments.

- **Sandbox accounts:** Users who only have a test account and no live Salesforce account.

A **CKO merchant** is a business that has both a live/sandbox account and is actively processing transactions with Checkout.com.

⚠️Queries from non-CKO merchants should be referred to the Sales team

PROCESS TO ESCALATE A NON-CKO MERCHANT CASE 🖊️

1. In the Zendesk ticket, go to the **Apply macro** search bar

2. Type "sales enquiry" and select the **Sales enquiry for dispatch** macro

 

1. Edit the email template as needed to address the specific merchant's query

4. Before submitting the case, change the case type to ensure it is categorised correctly:

- Form: Merchant Care

- Case Type: No action required

- No Action Required: Sales Enquiry

5. Submit the case to send the email to the merchant and automatically close the ticket. The macro will also tag the ticket as a **Sales Enquiry**.
