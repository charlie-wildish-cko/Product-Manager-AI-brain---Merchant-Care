**Use this article when**

A merchant has contacted us to query the issuer country field on the financial actions report or the settlement report.Overview 👀

The **Issuer Country** field identifies the specific country where the customer's credit or debit card was officially issued by a financial institution. This data point is standard across key financial documents, including:

- **Financial Action Reports:** Detailing lifecycle events of a payment.

- **Settlement Reports:** Used for reconciling funds received against sales made.

Merchant Response 🗣️

The "Issuer Country" field on the financial action or settlement report is populated with the country where the card was issued. 

This is represented using the ISO alpha-2 country code format (for example, "US" for the United States).

Refer to the documentation [here](https://www.checkout.com/docs/funds-management/retrieve-financial-reports/settlement-reports/financial-actions-by-payout-id-report#Report_fields).

**提问****：财务操作报告或结算报告中的“发卡国 (Issuer Country)”字段是从哪里获取的信息？**

**答:**

**报告中的“发卡国”字段填充的是该银行卡的实际发行国家 。**

**该字段使用 ISO alpha-2 国家代码格式（例如，“US”代表美国）。**  
**更多详情请参考文档 ******[here](https://www.checkout.com/docs/funds-management/retrieve-financial-reports/settlement-reports/financial-actions-by-payout-id-report#Report_fields)**。**
