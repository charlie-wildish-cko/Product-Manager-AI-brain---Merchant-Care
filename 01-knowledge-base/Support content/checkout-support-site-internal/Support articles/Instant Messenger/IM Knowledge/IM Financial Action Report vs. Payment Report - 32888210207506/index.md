**Use this article when**

You need to understand the difference between Financial Action Report and a Payment Report.**Overview 💬**

| **Feature** | **Financial Action Report** | **Payment Report** |
| --- | --- | --- |
| **Primary Focus** | **Impact on Funds.** Tracks every event that changes your available balance. | **Transaction Status.** Tracks the lifecycle and details of a specific payment. |
| **Key Data Points** | Captures, Refunds, Fees, Adjustments. | Payment ID, Amount, Current Status (Pending/Captured). |
| **Best For** | Financial reconciliation and accounting. | Customer support and order tracking. |

### **Quick Decision Matrix for Agents**

| **If the Merchant asks...** | **Use this Report:** |
| --- | --- |
| "Is this payment successful?" | Payment Report |
| "How much did I pay in fees last Tuesday?" | Financial Action Report |
| "What is the status of a specific Refund ID?" | Payment Report |
| "Why did my available balance just drop?" | Financial Action Report |

**Merchant Response 🗣️**

- Purpose: It tracks every event that changes your available funds.

- Key Events: It includes actions such as Authorizations, Captures, Refunds, and Fees.

- Primary Use: Use this report to track and reconcile all financial movements that impact your available balance.

**Payment Report**

- Purpose: This report focuses on the status and specific details of individual payments.

- Key Details: It displays transaction-level data (e.g., Payment ID, Amount, and Current Status).

- 
Primary Use: Use this to view the lifecycle and basic information of a specific transaction
 

提问：财务操作报告 (Financial Action Report) 与支付报告 (Payment Report) 有什么区别？  
答：财务操作报告与支付报告的核心区别在于它们的侧重点不同： 

财务操作报告 (Financial Actions Report) 

- 它追踪每一个会改变您可用资金的事件。 

- 例如授权 (Authorizations)、确认 (Captures)、退款 (Refunds) 和费用 (Fees)

- 用于追踪和对账所有影响您可用余额的财务变动。 

支付报告 (Payment Report) 

- 该报告侧重于单笔支付的状态和详细信息。 

- 单笔支付的交易状态（例如：ID、金额、当前状态）。 

- 查看单笔交易的生命周期和基本信息。
