## Introduction

The [User Permissions page](https://www.checkout.com/docs/business-operations/use-the-dashboard/user-permissions) in Checkout.com Documentation is a key document to assist you with queries related to Access & Permissions and you should always have this to hand when handling these queries.  

## Key Terms & Definitions

| **Term** | **Definition** |
| --- | --- |
| **SSO** | Single Sign-On |
| **IDP** | Identity Provider |
| **IAM** | Identity and Access Management |
| **SFTP** | Secure File Transfer Protocol |
| **SAML** | Security Assertion Markup Language |
| **MFA ** | Multi-Factor Authentication |
| **OTP** | One-Time Password |
