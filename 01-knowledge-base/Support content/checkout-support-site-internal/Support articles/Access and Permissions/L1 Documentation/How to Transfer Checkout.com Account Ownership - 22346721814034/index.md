**When to use this article**

When a merchant requests a change to ownership of a Checkout.com account.

## INTRODUCTION  💬

The merchant needs to change the account owner for their Checkout.com account. This process must be initiated by an existing user with the appropriate permissions, and the new owner must be an existing user on the platform. 

 

## KEY TAKEAWAYS 🔑

- An **Account Owner** or **Account Manager** can request an ownership change

- An **Account Admin** can also request a change, but only with a valid reason and the approval of the existing owner or an Account Manager

- The new account owner must already be an existing user on the platform before the transfer can be completed

- The process involves verifying user permissions, gathering required information and submitting a request to the Merchant Configuration team

## PROCESS FOR ACCOUNT OWNERSHIP TRANSFER 🖊️

This process is a standard procedure that requires verification of user permissions and a clear, step-by-step approach to gather information and submit the request. The primary tools used are the **Client Admin Tool (CAT)**, the **Checkout.com Dashboard**, and **Zendesk**.
Step 1. Check User Permissions

- 
**Verify Permissions:** Confirm the user initiating the request has the authority to do so, such as being an Account Owner, Account Manager, or an Account Admin with valid justification.

- 
**Method 1: Check on Dashboard (NAS):**

  - Log in to the NAS dashboard and select the merchant account

  - Go to **Settings Roles and permissions**

- Search for the user's email to verify their assigned permissions.

- 
**Method 2: Check on Client Admin Tool (CAT):**

  - Access the Client Admin Tool (CAT)

  - Navigate to **Client>Dashboard>Dashboard Users**

- Find the user's email in the list to confirm their permissions

Step 2. Gather Required Information

Collect the following details from the merchant to submit the request:

- 
**Email Address of New Owner:** The email of the user who will take ownership

- 
**Rationale for Change:** A clear reason for the ownership transfer

Step 3. Initiate the Request

- Submit a change of ownership request to the regional Merchant Configuration team

- If the new owner is not yet a user, the current owner or admin must add them first

- Use the **Account Ownership transfer - add new owner** macro to email the merchant, which includes login information for the new user

- The new owner will receive an email and must log in to finalize their user account

- Verify a successful login by checking the user's details on CAT; their username will be visible if they have logged in

- Once the new user has logged in and confirmed, the Merchant Configuration team will transfer ownership

## RESOLUTION ⚒️

After the Merchant Configuration team has completed the ownership transfer, you must inform the merchant that the change has been finalized. 

You can use the **Account ownership transfer - completed** macro for this notification

## ESCALATION** ⏫**

If an account does not have an Account Owner or Account Manager, this is a rare situation that requires further investigation, especially if the merchant has been terminated.

- 
**Required information:** Provide a clear summary of the case and the investigation steps taken.

- 
**Instructions for the agent:** Remain on the case, monitor for updates, and notify the merchant of any developments.

## FAQs** ****❓**

What if the new owner is not an existing user on the platform?

The current account owner or an admin must add the new user to the platform before the ownership transfer can be initiated. The new user must then log in to their account to finalize their profile before the ownership transfer can be completed.Can an Account Admin request an ownership change?

An Account Admin can request a change of ownership, but they must provide a valid justification and get approval from the existing Account Owner or an Account Manager.How can I verify if the new user has logged in?

You can check their user details on the Client Admin Tool (CAT). If their username is visible in CAT, it confirms that they have successfully logged in.
