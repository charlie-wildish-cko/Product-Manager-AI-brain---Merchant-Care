## Tools & Permissions

Below are the tools that Merchant Care uses to handle issues related to Access & Permissions:

| **Tool** | **Purpose** |
| --- | --- |
| **Dashboard ** | The Dashboard is a single source for keeping track of and analyzing all payments in terms of critical performance indicators, payment history, data, and analytics.  The Dashboard is the Portal version for merchants on the New Account Structure (NAS) and Gateway Core (GWC). |
| **CAT Admin Tool ** | The Client Admin Tool (CAT) is a user interface (UI) plugin and API. The internal admin tool is used by the Merchant Configuration team to setup new clients and manage the configuration settings of our customers' accounts on the New Account Structure (NAS). The Client Admin Tool integrates directly into the NAS product network, reflecting the most up to date product offering from the respective domains. Merchant Care agents can use CAT Admin Tool to verify user configuration settings during their case investigation. |
| **ABC/HUB** | Legacy account structure/environment for Checkout merchants |
| **Okta Admin Tool ** | Platform to which all L1 agents have access, where agents can assist merchants with their login. Links:   - [Production](https://authcheckout-admin.okta.com/admin/dashboard)  - [Sandbox](https://authsandboxcheckout-admin.okta.com/admin/dashboard) |
| **NAS** | New Account Structure. This is the new account environment that all Checkout merchants are moving to |
| **Zendesk ** | Case management platform for handling merchant tickets and responses. |
