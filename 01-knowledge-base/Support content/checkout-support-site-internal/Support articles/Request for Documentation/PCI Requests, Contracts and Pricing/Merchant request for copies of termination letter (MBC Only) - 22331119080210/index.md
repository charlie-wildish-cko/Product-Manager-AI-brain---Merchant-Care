Process Steps

A Salesforce Queue has been built ([Case Type = Terminations)](https://checkout.lightning.force.com/lightning/o/Case/list?filterName=00BTs0000034UFVMA2) to retrieve all termination notices sent to the merchant by the Merchant Care Team.

How to log in to Salesforce?

1. Login to [OKTA](https://checkout.okta.com/app/UserHome)

2. Navigate to the [Jira](https://checkout.atlassian.net/servicedesk/customer/portal/111/group/296/create/274) and request access to [Salesforce here](https://checkoutsupport.freshservice.com/support/catalog/items/55).

  1. User Type: Internal - CKO Staff

  2. Reason: Work tool for Merchant Care

  3. Team: Merchant Care

  4. Usage Frequency: Daily

3. Once Access has been granted, you can view the [Termination Queue here](https://checkout.lightning.force.com/lightning/o/Case/list?filterName=00BTs0000034UFVMA2).

4. Search for the merchant and retrieve the conversation about the termination letter that was sent.
