## Process Steps

Merchant Sign-in to the Security Metrics Portal

Below are the steps that a merchant takes when signing into the portal:-

| Here is the first email notification template sent to merchants by Security Metrics Ltd. |  |
| --- | --- |
| This is the reminder email notification template |  |
| After having clicked the link in the email from CKO, they will see the first email template filled in with their details accordingly - a generic example can be shown on the right-hand column |  |
| Merchants will be redirected to the Security Metrics Portal where the user should sign up as a first-time user by clicking on “Sign Up” which is found at the bottom of the page. |  |
| Users will be required to fill out the Sign Up page. |  |
| Once the above is completed, the user needs to verify the authenticity of their sign-up information and their email.      Once the email confirmation has been approved, the merchant will be redirected to the Sign-in page. |  |
| Once the user has authenticated this email registration, the latter will be redirected to the login page where he can now sign in. |  |

Merchant Care Sign-in to the Security Metrics Portal

Below are the steps that Care teammates take when signing into the portal:-

| **Process** | **Screenshots** |
| --- | --- |
| Login to [https://lastpass.com/vault](https://lastpass.com/vault/) and look for Security Metrics ( Merchant Care) |  |
| Click on Launch |  |
| This will redirect you to the Security Metrics Portal: [https://www.securitymetrics.com](https://www.securitymetrics.com/)      Click on Login. |  |
| The Credentials will be automatically populated. |  |
| Once logged in:  1. You can browse for details you are looking for  2. To search for CKO merchants   1. Go to the “Accounts” Tab next to Dashboard   3. Use the search field by choosing **Company Name** to look for your merchants |  |
| Scroll down to find the merchant details and Status.  - Merchant ID (Security Metrics)  - Company Name (Client Name registered with CKO)  - Email address (of CKO user)  - Enrollment Status   - Compliance (Present Status) |  |
| Click on the Merchant ID for further details on the client |  |
