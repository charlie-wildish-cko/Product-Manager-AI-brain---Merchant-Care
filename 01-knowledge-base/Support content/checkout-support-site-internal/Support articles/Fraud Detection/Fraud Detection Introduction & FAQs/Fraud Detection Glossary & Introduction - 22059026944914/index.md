| **Term** | **Definition** |
| --- | --- |
| **CKO** | Checkout.com |
| **CAT** | Client Admin Tool |
| **Fraud Detection Tool/ FDT** | Checkout's Risk Engine gives merchants control over transaction risk assessment by offering modular rules, customisable workflows, and machine learning capabilities across a wide range of data domains. |
