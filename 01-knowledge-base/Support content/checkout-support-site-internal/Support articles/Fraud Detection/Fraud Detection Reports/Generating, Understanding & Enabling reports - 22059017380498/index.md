## Introduction

This article outlines the procedure for generating, downloading, and understanding Fraud Detection Reports available to merchants.

## Process Steps

### Generating a New Fraud Detection Report

1. 
**Access Reports Screen:**

  - Navigate to the Reports screen on the merchant dashboard.

2. 
**Create a New Report:**

  - Select the ‘Generate Reports’ option.

1. 
**Select Report Type:**

  - From the dropdown menu, choose the report type you wish to generate.

2. 
**Set Date Range:**

  - Input the desired date range for the report.

3. 
**Choose Report Fields:**

  - Select the specific fields you need to include in the report.

4. 
**Generate Report:**

  - Click on ‘Generate Report’. Note that reports with extensive data may take some time to generate.

  - Once completed, the report will be available for download from the Reports screen.

### Understanding the Report Content

The downloaded report provides a detailed summary of each transaction, including:

- Data points collected

- Rules triggered during the transaction

- Outcome at each stage

- Identification of any fraudulent transactions

**Note**: The figures in the Fraud Detection Report do not match the Risk Analytics data displayed on the Fraud Detection dashboard.

### Daily Fraud Reports

Merchants can enable daily fraud reports from Visa and Mastercard by setting up webhooks. This can be done directly through the dashboard by navigating to Developers → Fraud → and enabling ‘Fraud Reported’.
