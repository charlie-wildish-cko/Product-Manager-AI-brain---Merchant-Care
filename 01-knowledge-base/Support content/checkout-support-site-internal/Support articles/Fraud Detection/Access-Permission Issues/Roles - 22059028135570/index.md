## Introduction

Dashboard owners can control what their users can access with User Permissions, a set of roles that can be applied to a group of users. If a client has multiple entities, they can also decide which of these each user can access.

Permission to edit decline lists and risk rules is given to Owners, Risk managers and Admin users only.

## Process Steps

- Users will be able to review roles and permissions via the Dashboard (settings → user permissions). 

- As well as being able to view users via the dashboard, internal CKO agents are also able to find this on CAT (Dashboard → Dashboard users).

**Please refer merchants to the following documentation which defines the available roles and permissions and how to manage users: ******[User Permissions](https://www.checkout.com/docs/business-operations/use-the-dashboard/user-permissions)
