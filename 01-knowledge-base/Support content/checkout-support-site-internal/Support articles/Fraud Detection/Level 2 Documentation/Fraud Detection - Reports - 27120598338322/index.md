**When to use this article**

For information about Fraud Detection Reports in Dashboard, how this works and who to raise the request with

**Problem / Symptom**: Common causes include information about our fraud reports or questions about the data in the fraud reports.

## DESCRIBE THE ISSUE 💬

- The merchant asks questions about how and where to get data on Fraud

## KEY TAKEAWAYS 🔑

- Merchant fraud data is available via two main reports

- The "Fraud Detection Report" is owned by the Fraud Detection team

- The "Reported Fraudulent Transactions" report is owned by the Data Analytics team

- Access to reports is granted via a request form

- Escalation depends on the report type

## TOOLING 📍

| Dashboard |
| --- |
| Raise a request through the form [here](https://checkoutsupport.freshservice.com/support/catalog/items/315) and once granted it can be accessed through the link [here](https://dashboard.checkout.com/). |

## PROCESS FOR FRAUD DETECTION REPORTS 🖊️

Most requests currently involve directing users to the correct team, so extensive troubleshooting isn't typically needed. Downloading the relevant report helps identify discrepancies.

- There are two main reports available in the dashboard, found in three locations: 

### Fraud Detection Report (2 locations)

**Dashboard Performance Page**

Owned by Fraud Detection:

- Payments > Performance > Generate report > Report Type: Fraud Detection

- Encourage people to use the reports on the reports page below

**Dashboard Reports Pages**

- Owned by Fraud Detection with options to select fields and no time limit:

  - Reports > Create report > Report Type: Fraud Detection

### Reported Fraudulent Transactions

Owned by @Hamish Chreseson and his team which falls under the Data Analytics team:

- Reports > Create report > Report type: Reported Fraudulent Transactions

### Fraud Detection Report Source

Fraud Detection have the report running off the same source as other reports (Snowflake table: fct_payin), so a number of common queries should have been reduced.

More information on these 2 reports and the current fields which are supported can be found in our public docs below:

- [Fraud Detection Report](https://www.checkout.com/docs/business-operations/prevent-fraud/retrieve-fraud-reports/fraud-detection-report)

- [Reported Fraudulent Transactions Report](https://www.checkout.com/docs/business-operations/prevent-fraud/retrieve-fraud-reports/reported-fraudulent-transactions-report)

## RESOLUTION 🛠️

- If it's about the Fraud Detection report, raise with the Fraud Detection L3 using the form [here](https://checkoutsupport.freshservice.com/support/catalog/items/588).

- If it's about the Reported Fraudulent Transactions Report, raise it with @Hamish Chreseson and team by either raising a request [here](https://checkoutsupport.freshservice.com/support/catalog/items/146) or asking in [#ask-analytics](https://checkout.enterprise.slack.com/archives/CEH79Q55M).

## ESCALATION ⏫

- Same as the resolution stated above
