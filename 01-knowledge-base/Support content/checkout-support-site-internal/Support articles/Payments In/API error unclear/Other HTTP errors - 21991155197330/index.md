## Process Steps

1. Any other **API HTTP error **e.g. configuration 

  1. Transactions can get declined e,g currency is not enabled/ if a payment method is not configured. Then get the Config team to enable this currency or payment method. E.g 3DS may be declined as this is not enabled. 

    1. 
**Note**: An MCR would need to be raised if the processing currency is not enabled. Follow the process [here.](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/5974065301/NAS+MCRs+where+Merchant+Care+is+the+Requestor#Add-New-Processing-Currencies) 

  2. If you get any other issue with HTTP error you can send this to L2 who will be able to review and respond back directly to the merchant

    1. Do this by assigning the ticket on Zendesk to L2
