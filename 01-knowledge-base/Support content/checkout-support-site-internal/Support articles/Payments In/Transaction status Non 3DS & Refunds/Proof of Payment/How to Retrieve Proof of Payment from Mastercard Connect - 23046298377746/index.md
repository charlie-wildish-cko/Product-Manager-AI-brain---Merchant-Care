**Issue Type: **Transaction status (Non 3DS & Refunds)

**Reason: **Proof of payment (ARN, RNN, bulk)

## Process Steps

To retrieve transaction clearing details for a particular transaction from MCconnect, the below information is required:

- The region of the transaction being investigated

- Acquirer Reference Number

- Date of transaction

- Amount and Currency

💡**Tip:** Instead of using Hermes, you can find all the details from agent toolkit.   

If entity is available on this tab, then you can find region as well. 

💡**Tip:** Script to use to retrieve details in bulk:

Tool: Hermes   
Server: Production(prod-agl1) - Read19 (App.DataTool.Merlin_DB_Clearing_Support)  
Database: Integration

```SELECT Paymentid,ARN,ClearingStatus,TransactionAmount,TransactionDate, *
FROM "LANDING"."INTEGRATION"."MC_OUTGOINGTRANSACTION"
WHERE arn = 'XXXXXXXXXXXXXXXXXXXXX'

or 

select Clearingstatus,Messagetype,Paymentid,MastercardTransactionId, *from INTEGRATION.mc.OutgoingTransaction
where arn in ('82700924319771072586872','09313394173026491033466')
```

1. Gather all the above information

2. Log in to [Mastercard Connect](https://www.mastercardconnect.com) using the appropriate credentials as per the Region of the transaction

  1. Open RSAToken Application

  2. Enter the 4 Digit PIN

  3. Copy the 8-digit Token Code generated by the RSA Token

  4. Enter both the username and the 8-digit code and click Sign In

1. On the main screen, click **More+** in the bottom left-hand corner:-

1. Select **Transaction Investigator **at the end

1. Click on **Advanced Search**

1. On the Advanced Search page, enter the Transaction **Acquirer Reference Number** and **Date** interval of the transaction, and click on **Search**:-

1. When the transaction details appear, cross-check if the transaction details and amount match the requested data. Click the **Export and Print** button:-

1. 
Select PDF and click OK:-
