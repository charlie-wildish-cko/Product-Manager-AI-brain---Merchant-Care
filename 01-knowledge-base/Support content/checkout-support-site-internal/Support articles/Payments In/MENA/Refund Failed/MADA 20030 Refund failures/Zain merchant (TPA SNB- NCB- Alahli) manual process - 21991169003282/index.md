## Introduction

**Important**: KSA has a manual refund process due to the 30 day limitation for MADA. All other acquirers outside of KSA can be done directly from the Dashboard. For manual refunds please refer to this [highspot page](https://docs.google.com/spreadsheets/d/1g1I4-FixwMxsF07SLu_3mtin_650uVW-0MVOzS84xg8/edit#gid=1386391676) which gives you a breakdown of the process for KSA acquirers.

## Process Steps

1. Once the ticket is received, fill in the template below (obtain details from Retool): 

| Payment ID | RRN | Auth Code | MID | Date of TRX | TRX Amount | Refund Amount | Masked Card Number |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

1. Share it with SNB/ Alahli bank contact: 128003@alahli.com

2. Once the ticket is created, the contact will share back the request number.

3. After 3 business days raise a follow up with SNB contact, using the request numbers. They will share the status, if completed with the claim IDs.

4. Please share the claim IDs back to the merchant.

_**Note: **Please note that the above is a refund process for SNB which is specific to the merchant Zain. For all other merchants processing with SNB/NCB/Alahli the merchant can do the manual refund directly from the acquirer's Ecorp portal. The merchant can refer to the attached document (see bottom of document) to see the step by step procedure of how to do the manual refund on the portal._
