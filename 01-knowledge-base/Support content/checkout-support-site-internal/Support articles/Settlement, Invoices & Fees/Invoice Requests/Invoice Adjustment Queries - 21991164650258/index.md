## Introduction

Today, when a **merchant **looks at their statements, they see “adjustment” on them but **lack the breakdown or details behind it.**

This** information is available in 2 reports**; one for MBC and one for NAS, which Merchant Care can access and obtain information from, as shown below. If you do not have access to the reports, please request access through the Analytics Support request below. 

| **Resource** | **Description** |
| --- | --- |
| [NAS Adjustments](https://checkoutinternal.eu.looker.com/looks/8998) | Allows you to check:  - If certain adjustments have been adjusted,  - The nature/reason of a certain adjustment in a merchant’s statement on NAS |
| [MBC Adjustments](https://checkoutinternal.eu.looker.com/looks/4349) | Allows you to check:  - If certain adjustments have been adjusted,  - The nature/reason of a certain adjustment in a merchant’s statement on MBC |
| [Analytics Support request](https://checkoutsupport.freshservice.com/support/catalog/items/146) | For adjustment reporting access, a ticket can be submitted here (this should be submitted by Care Leaders on behalf of teammates). |

To access the reports and find the relevant information to be able to respond to the merchant’s query, Merchant Care should follow the below steps.  
 

## Process Steps

### Adjustment Queries on NAS

| **Step** | **Additional Information** |
| --- | --- |
| Open NAS adjustment report on [Looker](https://checkoutinternal.eu.looker.com/looks/8998) | See the Resources table above for more information on the report |
| Under the filter section:   - Select your date range (this can be changed to a specific date for the year),  - Select your client name from the drop-down. |  |
| Once search results are displayed, the following information is available to help answer the merchant’s query:  - Adjustment reason (this usually includes the case number),  - Created by (the person who processed the adjustments),  - Adjustment type (fees, top-up, or client settlement return). |  |
| Use the information obtained to reply and resolve the merchant’s query on Zendesk |  |

### 

### Adjustment Queries on MBC

| **Step** | **Additional Information** |
| --- | --- |
| Open MBC adjustment report on [Looker](https://checkoutinternal.eu.looker.com/looks/4349) | See the Resources table above for more information on the report |
| Under the filter section:   - Select your date range (this can be changed to a specific date for the year),  - Select your client name from the drop-down. |  |
| Once search results are displayed, the following information is available to help answer the merchant’s query:  - Adjustment note (this usually includes the case number),  - Statement date |  |
| Use the information obtained to reply and resolve the merchant’s query on Zendesk |  |
