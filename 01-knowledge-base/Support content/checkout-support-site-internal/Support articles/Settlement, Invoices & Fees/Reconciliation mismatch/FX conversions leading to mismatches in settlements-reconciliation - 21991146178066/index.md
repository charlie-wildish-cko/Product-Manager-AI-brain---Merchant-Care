## Process Steps

1. If Merchant Care L1 receives a query on FX conversions that have led to mismatches and confusion with settlements/reconciliation, the L1 Merchant Care agent would need to escalate the query to L2. L2 will be able to do FX calculations and explain these to the merchant and, if additional help is required, they will be able to escalate to L3.

2. To do this, L1 agents should follow the Zendesk guidance for transferring to L2 [here](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/5991727266/Case+Handling+-+SOP#Collaborating-between-Merchant-Care-L1-%26-L2-teams).
