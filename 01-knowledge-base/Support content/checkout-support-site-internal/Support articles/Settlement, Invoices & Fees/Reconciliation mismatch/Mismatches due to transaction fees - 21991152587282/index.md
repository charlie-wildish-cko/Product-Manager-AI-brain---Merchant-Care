## Introduction

A transaction can appear in several reports, however, not all reports will show all fees, e.g. interchange fees, scheme fees, etc. As such, merchants can get confused about the value of the settlement that they should be receiving vs the value of the transactions performed.

## Process Steps

Merchants should be checking their transaction fees in the “Financial Action Report by Date Range” in the Dashboard - to obtain this, merchants should:

1. Login to Dashboard

2. 
Go to the Reports tab, then click on “All Reports” and then click on “Generate reports”

3. Select “Financial Actions” from the Select type drop-down

4. If applicable, select the account that you want to get this information for

5. Select the date range for the report to cover

6. 
Click on “Generate Report”

7. 
Click on the Green download icon to download the report

8. For further information on Financial Action reports and understanding them, talk the merchant through the information in the “[Financial Actions Reports](https://www.checkout.com/docs/business-operations/retrieve-reports/reconciliation-reports/financial-actions-reports)” Documentation page and send this page to the merchant for reference

9. Agents can also share the [Reconciliation with Checkout.com](https://www.checkout.com/docs/business-operations/retrieve-reports/reconciliation-reports/reconciliation-with-checkout-com) document link which gives merchants an overview of how to reconcile with different reports
