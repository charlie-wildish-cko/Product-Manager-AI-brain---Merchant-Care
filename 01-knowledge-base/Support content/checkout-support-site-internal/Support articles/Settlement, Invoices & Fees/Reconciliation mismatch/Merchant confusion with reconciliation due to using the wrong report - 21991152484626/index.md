## Process Steps

**Choosing the report to reconcile with**

Merchants should use the Payouts report to reconcile, not the Payments report.

The **Payout report** provides a payout summary over a certain period, as shown below:

If the merchant would like to reconcile with a full breakdown, they would need to download the** “Transaction breakdown”, **which can be found at and downloaded from the bottom of the page of any settlement, as shown below. This will provide the merchant with full details of each payout:

  
  
 

To obtain the Payouts reports, merchants should: 

1. Login to Dashboard

2. 
Go to the Reports tab, then click on “All Reports” and then click on “Generate reports”

3. Select the required report, e.g. “Payouts” as shown below, from the Select type drop-down

4. If applicable, select the account that you want to get this information for

5. Select the date range for the report to cover

6. 
Click on “Generate Report”

7. 
Click on the Green download icon to download the report 

In addition to the above, Merchant Care can also talk the merchant through the information in the [Reconciliation with Checkout.com](https://www.checkout.com/docs/business-operations/retrieve-reports/reconciliation-reports/reconciliation-with-checkout-com) Documentation page and send this page to the merchant for additional information.
