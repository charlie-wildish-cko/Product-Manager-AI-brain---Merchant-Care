## Process Steps

1. If the Merchant Care team cannot find the settlement in any report, it could be that this is a gross settlement merchant, in which case Merchant Care would not be able to see on their end. The only team that can see gross settlement reports is the Payments team. 

  1. If L1 sees this scenario, they would need to escalate the query to L2. If L2 is also not able to find the settlement, they will escalate to the Payments team. 

2. To do this, L1 agents should follow the Zendesk guidance for transferring to L2 [here](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/5991727266/Case+Handling+-+SOP#Collaborating-between-Merchant-Care-L1-%26-L2-teams).
