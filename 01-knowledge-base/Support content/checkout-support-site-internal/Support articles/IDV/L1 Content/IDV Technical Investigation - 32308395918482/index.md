**When to use this article**

This guide provides a step-by-step process for investigating and resolving issues related to merchant identification verification (IDV) tickets in Zendesk.

Classification Type: Technical Investigation

### **The issue 💬**

When a user encounters a bug during the journey, the merchant may contact us for assistance. In this case, you can ask our technical team to launch an investigation, provided you have a valid idv id number. 

If the IDV number is not valid and returns no results on Looker, then you need to request a valid ID number before raising a technical query.

| Use this macro to respond to ask for a valid IDV ID: IDV > Invalid IDV ID. |
| --- |

| Use this macro to respond to a technical investigation: IDV>Transfer> Ask IDV Debug |
| --- |
