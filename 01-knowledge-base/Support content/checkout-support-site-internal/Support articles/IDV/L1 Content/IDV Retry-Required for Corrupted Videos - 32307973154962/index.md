**When to use this article**

This guide provides a step-by-step process for addressing issues related to corrupted videos in IDV tickets. The reason for retry in Looker shows corrupted_videos. 

Category is Verification Inquiry.

### **The issue 💬**

We may return the "corrupted_videos" code when we are unable to read the videos captured by the user during the journey. In this case, you must ask the Account Managers if the code is legitimate and then respond to the merchant.
