**When to use this article**

When responding to an IDV case you can use these macros which will populate a response or an action for you.IDV Macros Guide ✨ 

| **Macro Name** | **Use this when** |
| --- | --- |
| Care>IDV AMs Escalation | You need to escalate a case to an IDV account manager |
| Contact Docusign | End user needs to contact Docusign, as Checkout.com have successfully completed the identity verification |
| Contact Support Team | The end user needs to contact the support team of the organisation that requested the verification |
| Data mismatch | The data entered by the end user does not match the data extracted from the ID document |
| Formal Complaint | The merchant or end user is making a complaint |
| ID Document Damaged | The ID document is damaged and therefore invalid |
| ID Document Expired | The ID document is invalid due to expiry date being in the past |
| Invalid IDV ID | The ID reference is not a Checkout.com reference and does not correspond with our system details |
| Personal Data Deletion Merchant Request | The merchant has requested deletion of the end user's personal dat |
| Personal Data Deletion Request | The end user has requested their personal data be deleted |
| Privacy Concerns | Escalate the case to the account managers due to privacy concerns being raised by the merchant |
| Retry Required | The merchant must send a new verification link to the end user as the video asset did not record |
| RFO | You must attach a document outlining the reason for outage RFO as confirmed by the IDV tech team |
| Transfer > Ask IDV Debug  (via Zendesk > Slack message) | Escalate technical investigations to the IDV tech team Example: Issue pre IDV ID creation |
| Transfer > Ask IDV Fraud Ops (via Zendesk > Slack message) | Escalate a request to update the name or document number on the system to match the ID document, an error occurred when scanning |
