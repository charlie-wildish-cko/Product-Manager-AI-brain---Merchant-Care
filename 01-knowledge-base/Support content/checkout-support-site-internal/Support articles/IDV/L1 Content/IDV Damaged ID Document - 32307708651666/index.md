**When to use this article**

A step-by-step guide for handling damaged document tickets for IDV cases in Zendesk and Looker. The merchant will have received a status of rejected or retry-required. 

Case Classification: verification inquiry.

**The issue 💬**  
Merchants may inquire about the "document_damaged" code we return, we cannot accept documents that are damaged. In this case, you must ask the Account Managers if the code is legitimate and then respond to the merchant.
