**When to use this article**

This guide provides a step-by-step process for handling expired document tickets in Zendesk. Use this when the reason for decline in Looker shows: document is expired. 

Category is verification inquiry.

### **The issue 💬**

Merchants may inquire about the **"document_expired"** code we return (we cannot accept expired documents, with the exception of French ID cards whose validity period has been extended). In this case, you must escalate to the Account Managers and then respond to the merchant.
