**When to use this article:**

To talk the merchant through how to view and add a processing channel on dashboard, the merchant can self-serve these actions INTRODUCTION 💬

As part of our efforts to improve the merchant experience in Dashboard and drive self-service, merchants will not only be able to view processing channels and specific processing channel details, but they will also be able to:

- Request a new processing channel

- Request a new URL to be added under a new processing channel

See the [Manage Processing channel external-facing](https://www.checkout.com/docs/business-operations/use-the-dashboard/manage-processing-channels) content

⚠️ Note: Merchants can't self-serve on sandbox, they will need to contact us to perform this action on the sandbox environment. PROCESS STEPS 🖊️

Request a New Processing Channel

If a merchant reaches out about requesting a processing channel on Dashboard, they can find it as follows:-

- Log in to [Dashboard](https://dashboard.checkout.com/)

- Click on Settings (gear icon on the top right)

- Under **Business Settings**, click on **Processing** **channels**:-

- Here they will see the various channels by name, ID and associated MCCs. They will also see a **+Request new channel **button:- 

- Complete the general information section, such as the processing channel name, redirect URLs (optional), and toggle the relevant payment methods. Please note:

  - When they enable a payment method, they need to specify which MCC(s) to enable (if a merchant only has one MCC configured on their entity, they will not be asked to select an MCC)

  - If enabling Amex, the merchant will need to specify annual processing volume (expected), customer service phone number, and email

- Upon clicking "Continue," they will be taken to the next screen to complete the billing descriptor information. 

- The requirements section will confirm if the static billing descriptor entry meets our criteria as it's typed in (all green indicates a valid billing descriptor):

- Information from existing processing channels, such as MID, authentication settings, and full card API/MOTO settings, will be used to help set up the new channel. 

- If the merchant wants to change any of these, they can click on **request support** at that moment or contact their Account Manager

- Upon clicking continue, a confirmation screen appears to confirm that all entered information is correct. If anything is inaccurate, they can click **Back** to make corrections. If correct, they click **Submit**:-

- A dialogue box will appear to confirm that the request has been submitted:

- Merchants will receive a confirmation email of their submitted request:-

Request a New URL Under a New Processing ChannelMerchants can now add a New URL under the "Request new processing channel" section on Dashboard.
