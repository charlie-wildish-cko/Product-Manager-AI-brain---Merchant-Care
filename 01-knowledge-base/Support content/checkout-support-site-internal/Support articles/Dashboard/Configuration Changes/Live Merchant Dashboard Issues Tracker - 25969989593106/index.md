To help you stay updated on known or emerging issues related to the Merchant Dashboard, use the Live Issues Tracker. 

**Always check this dashboard before escalating or raising a new case about the Merchant Dashboard.**

### WHERE TO FIND IT 🧭

[Merchant Dashboard Issues Tracker](https://checkout.atlassian.net/jira/dashboards/14679)  

## WHEN TO USE IT ✅

- You’re handling a case where the merchant reports an issue with their dashboard (login issues, data not displaying, errors)

- You want to check if an issue is already known and being worked on

- You need status updates to communicate with the merchant 

## WHAT YOU'LL SEE 📌

- **Summary: **A short summary of the problem

- **Priority:** Shows as a 'P' 

- **Impact: **Rating to show impact

- 
**Status**: Done, In Progress, Parking Lot
