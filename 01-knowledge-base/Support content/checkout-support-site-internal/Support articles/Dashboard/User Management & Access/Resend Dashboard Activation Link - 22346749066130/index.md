## Introduction

This article outlines the steps for L1 support agents to handle password reset requests for Checkout.com accounts by directing merchants to the self-serve option.

**Before you begin: **

- 
**Identifying which Reset Platform to use** - please use the respective link:

  - 
**Production**: [Production link](https://authcheckout-admin.okta.com/admin/dashboard)

  - 
**Sandbox**: [Sandbox link](https://authsandboxcheckout-admin.okta.com/admin/dashboard)

- 
**SSO Configuration:**

  - If the merchant account utilizes Single Sign-On (SSO), direct the merchant to their designated SSO manager for password reset.

## Process Steps

- 
**Self-Service: **

  - 
**Article for self-serve:  ******[Reset your Dashboard password – Checkout.com](https://support.checkout.com/hc/en-us/articles/14327316567826-Reset-your-Dashboard-password)**. **

    - Encourage users to attempt a self-service password reset through [this link](https://identity-sandbox.checkout.com/signin/forgot-password) 

  - Merchants can use [this article](https://support.checkout.com/hc/en-us/articles/14327316567826-Reset-your-Dashboard-password) for further assistance, and agents should also aim to explain to the merchant via email that they should use the “Forgot Password form” from the dashboard login page. 

    - If the user cannot self-serve, please use the guidance in the [Password Reset Process article](https://checkoutint.zendesk.com/hc/en-us/articles/22346749106194-Password-Reset-Process) to reset the merchant's password. 

- 
**Activation link resends:**

  - Activation link resends are typically requested by users who were recently added to the Dashboard but have not yet completed the onboarding process. These requests can be identified in the resend password platform as indicated in the provided image.

  - To resend the activation link, we need to search for the user's e-mail address > Resend Activation Email ****
