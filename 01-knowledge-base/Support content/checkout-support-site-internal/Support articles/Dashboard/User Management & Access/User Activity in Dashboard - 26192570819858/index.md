Use this guide to support the merchant if they want to view and download logs of all user activity on their Dashboard account. 

This enables them to perform audits and resolve security issues or concerns. Process Steps 

| To view and download user activity logs, the merchant must be an 'administrator owner' or 'administrator' on the dashboard account Only successful activity appears in the logs- failed actions are not displayed |
| --- |

If a merchant reaches out about the User Activity on Dashboard, they need to take these steps:

1. Sign in to the [Dashboard](https://identity.checkout.com/)

2. Select the **Settings** menu in the top navigation bar

3. Under **Team settings** select **User activity**

4. Or use the **Download** option to download the user activity logs

5. For every action taken on the account, the following information is displayed:

  - The role and email address of the user who took the action

  - The timestamp of the action

  - The browser, operating system, and IP address from which the action was taken

  - Additional action-specific data points

### **Escalations**

6. If the merchant experiences issues with **User Activity** visibility, escalate this to [#ask-merchant-change-requests-product](https://checkout.enterprise.slack.com/archives/C06AXSFML79) on Slack with the merchant details.
