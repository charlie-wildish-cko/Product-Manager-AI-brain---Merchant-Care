## Introduction

For this issue, the client must provide you with:

- The cardholder ID 

There are two main reasons why the client may not be able to create a card through their mobile app: 

- If KYB/KYC has not been completed for the client, and/or 

- If the cardholder does not have a user account on the Dashboard.

## Process Steps

Check if KYC/KYB is complete 

1. On Okta, click on Genesis

1. Click on the "Cases" tab, input the client details in the Search box, and click on the required client to open their record:-

1. 
On the left-hand side, expand "Case Analysis” and check whether there is a tick next to "KYC/KYB." If there is a tick next to this, as shown in the below example, this means that KYC and KYB have been done for the client:-

Actions required:

- If KYC/KYB has been completed on the client, check that a user account has been set up for the merchant on the Dashboard using the steps below

- If KYC/KYB has not been completed on the client, this is why the client cannot create cards. If this is the case, you can obtain more information about the KYC/KYB status from the underwriting team

Please follow these [case-handling steps](https://checkout.atlassian.net/wiki/spaces/CHEC/pages/5991727266/Case+Handling+-+SOP#Emailing-internal-partner-teams%3A) when contacting internal partner teams such as Underwriting.
