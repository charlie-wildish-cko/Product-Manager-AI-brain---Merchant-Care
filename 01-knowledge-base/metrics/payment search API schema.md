# Payment Search API — Field Descriptions

## Top-level (`data`)

- **`id`** — Unique payment identifier (Base32 encoded Charge ID).
- **`status`** — Current payment status (e.g. Approved, Declined).
- **`amount`** — The payment request amount in its original currency.
- **`currency`** — The original currency the payment was requested in (three-letter ISO code), e.g. GBP, USD.
- **`reference`** — An optional reference (such as an order ID) a merchant can use to identify the charge.
- **`metadata`** — Arbitrary key-value metadata attached to the payment by the merchant.
- **`requested_on`** — The time when the payment request was made.
- **`processing_channel_id`** — The identifier of the processing channel, e.g. `pc_6k7jcjztullutk6ahxsozrlw6q`.
- **`response_code`** — The latest relevant gateway response code for acceptance.
- **`response_summary`** — Short description of the acceptance gateway response code.
- **`last_four_card_digits`** — Last four digits of the card used for the payment.
- **`bin`** — Bank Identification Number — first 6 digits of the card used.
- **`card_expiry_month`** — Card expiry month.
- **`card_expiry_year`** — Card expiry year.
- **`issuer`** — Name of the card-issuing bank.
- **`issuer_country`** — Two-letter ISO country code of the card-issuing bank.
- **`avs_check`** — Address Verification Service check result.
- **`card_scheme_local`** — Local card scheme name (e.g. Visa, Mastercard).
- **`payment_method`** — For card payments: card scheme (e.g. visa). For alternative payment methods: the APM (e.g. klarna).
- **`scheme`** — The name of the scheme used for acquiring (e.g. Visa, Mastercard).
- **`card_type`** — Card type (Credit or Debit).
- **`card_wallet_type`** — Wallet type associated with the card (e.g. Apple Pay, Google Pay).
- **`is_disputed`** — Boolean indicating whether the payment has an open dispute.
- **`recommendation_code`** — Risk recommendation code returned by the risk engine.
- **`total_authorized`** — The authorised amount in its original currency.
- **`total_captured`** — The total value of captures and partial captures in the original currency.
- **`total_refunded`** — The total value of refunds and partial refunds in the original currency. Does not include unreferenced refunds.
- **`eci`** — Electronic Commerce Indicator — authentication assurance level used in the 3DS flow.
- **`three_ds_protocol_version`** — 3D Secure protocol version used for authentication.
- **`arn`** — Acquirer Reference Number — used for chargeback and dispute tracking.
- **`payment_type`** — An indicator that determines the type of charge as required by the card scheme, e.g. Regular, MOTO (Merchant-Offline/Telephone Order).
- **`type`** — Direction of the transaction (e.g. payin, payout).
- **`authentication_status`** — Outcome of the payment during authentication. Can be authenticated, failed, expired or rejected.
- **`risk_flagged`** — Boolean indicating whether the payment was flagged by the risk engine.
- **`risk_score`** — Numerical risk score assigned by the risk engine.

## `actions[]` (per-action detail)

- **`id`** — Identifier for the specific action within the payment.
- **`transaction_id`** — Identifier linking this action to the parent transaction.
- **`type`** — Action type (e.g. Authorization, Capture, Refund, Credit).
- **`processed_on`** — The time this specific action was processed.
- **`status`** — Outcome status of this action (e.g. Approved, Declined).
- **`amount`** — Amount associated with this action in the payment's original currency.
- **`auth_code`** — Authorisation code returned by the issuer.
- **`response_code`** — Gateway response code for this specific action.
- **`response_summary`** — Short description of the gateway response code for this action.
- **`reference`** — Reference associated with this specific action.
- **`fraud_score`** — Fraud score assigned to this action by the risk engine.
- **`authentication_experience`** — 3DS authentication flow used for this action (e.g. frictionless, challenge).
- **`reason_code`** — Reason code for the action outcome (e.g. decline reason code).
- **`sanction_screening`** — Result of sanction/AML screening applied to this action.
- **`processing.acquirer_reference_number`** — Acquirer-assigned reference number for this action.
- **`processing.acquirer_transaction_id`** — Acquirer-assigned transaction ID for this action.
- **`recommendation_code`** — Risk recommendation code for this specific action.
- **`processing_channel_name`** — Human-readable name of the processing channel used for this action.
- **`transaction_retrieval_reference_number`** — Retrieval reference number used for dispute and chargeback lookups with the scheme.
- **`scheme_merchant_id`** — The merchant ID assigned by the card scheme.
- **`card_acceptor_id`** — An ID which identifies the merchant account, generated by the acquirer.

## `dispute_details`

- **`id`** — Unique dispute identifier.
- **`status`** — Current status of the dispute.
- **`reason`** — Human-readable reason for the dispute (e.g. Fraudulent transaction).
- **`reason_code`** — Scheme-specific reason code for the dispute.
- **`initiated_on_date`** — Date the dispute was raised by the cardholder.
- **`submit_evidence_by_date`** — Deadline by which the merchant must submit dispute evidence.
- **`amount`** — Disputed amount in the payment's original currency.
- **`method`** — Payment method involved in the dispute (e.g. card).
- **`currency`** — Currency of the disputed amount (three-letter ISO code).
- **`description`** — Description of the disputed transaction.
- **`relevant_evidence`** — List of evidence types relevant to contesting this dispute.

## `acquirer_response`

- **`authorisation_code`** — Authorisation code returned by the acquirer.
- **`acquirer_response_code`** — Raw response code returned by the acquirer for the authorisation.
- **`authorisation_description`** — Human-readable description of the authorisation outcome from the acquirer.
- **`authorisation_codes`** — List of all authorisation codes associated with this payment (e.g. where multiple authorisation attempts occurred).
- **`capture_code`** — Acquirer response code for the capture action.
- **`capture_description`** — Human-readable description of the capture outcome.
- **`refund_code`** — Acquirer response code for the refund action.
- **`refund_description`** — Human-readable description of the refund outcome.
