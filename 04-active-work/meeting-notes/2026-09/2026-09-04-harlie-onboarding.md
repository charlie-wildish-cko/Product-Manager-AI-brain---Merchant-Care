**AI tooling and writing standards**
- Everyone at Checkout uses AI. Product and tech use it more advanced than other teams. Charlie's setup is the PM brain project with Claude on top, using GitHub for version control, VS Code with the Claude plugin plus the Claude app. Harlie has been using Claude and Ghostty. Jamie is an extreme tooling user. Charlie recommended Obsidian for editing documents.
- Standard: use AI freely for drafts and for Claude-only reference documents, but anything shared with a human must be human-edited and stripped of obvious AI phrasing. Charlie's project carries a style guide for this.
- Milan will challenge a document that reads as AI-written. Charlie named the failure mode: cognitive offloading, shifting interpretive effort onto the reader. In product, making yourself understood is the job.
- Sharing the PM brain project needs a process. It is currently single-user, and multi-user use risks source-control conflicts and overwrites.

**Decisions**
- Minimise AI-written language in anything shared for review. Human-edit for simplicity first.
